WebGL Primitive Playground

Practicum 2 moves from Canvas 2D to the GPU. Every shape below is vertex data uploaded to a buffer, connected to a shader through attributes, tinted through uniforms, assembled into primitives, and drawn with a draw call, all in Normalized Device Coordinates. Each section is live WebGL2.

The Playground

One program, one interleaved buffer, many draw calls. Three triangles with different brightness, three points with different sizes, lines, strip, loop, triangle strip and fan, plus three bouncing triangles, click-to-spawn points, and wave animation. Same shader, different uniforms per draw.

HUD

Pick Triangles, Points, or Lines, pick a color, then drag on the canvas to draw. Click works too for small shapes. Hold W A S D / arrows · R reset · Space pause · C random color.

Live data

How it works

  • Interleaved vertex: x, y, r, g, b in one buffer + VAO.
  • Attributes a_position + a_color; varying v_color carries color.
  • Uniforms change per draw: brightness, point size, wave.

Controls

  • One draw tool at a time; Triangles is default.
  • Swatches set draw color; RGB draws red-green-blue.
  • Drag to draw; click for a small shape.

Primitive selector

Same three vertices, three different assemblies. The draw mode, not the data, decides whether you see a triangle, three dots, or a closed outline.

mode

Pick a mode. Vertex data never changes.

Live data

How it works

  • gl.drawArrays(mode, 0, 3) with mode swapped.
  • gl_PointSize only matters for POINTS.

Controls

  • Click Triangle / Points / Lines.
B

Color control

Vertex colors interpolate across the triangle. Buttons rewrite the color buffer. The slider scales brightness through a uniform, data versus parameter.

color

Press a color, then drag brightness. Press Random a few times. Each click reshuffles all three vertex colors.

Live data

How it works

  • Buttons re-upload a_color buffer.
  • Slider sends u_globalBrightness.

Controls

  • Color buttons + brightness slider.
  • Random can be pressed many times for new colors.
C

Spawn primitive

Mouse pixels become NDC, NDC becomes a vertex. Every click appends one point to a dynamic buffer and draws it on the next frame.

click

Click anywhere to drop a point.

Live data

How it works

  • pixel → NDC: (x/w)*2−1, 1−(y/h)*2.
  • New vertex pushed with DYNAMIC_DRAW.

Controls

  • Click to spawn; Clear empties.
D

Multiple moving objects

Three triangles, three offsets, three velocities. Each bounces off the NDC walls on its own. One shader, different uniforms per draw.

moving

Just watch. Each triangle has its own speed.

Live data

How it works

  • Per-object offset += velocity each frame.
  • Hit ±1 wall? Velocity flips.

Controls

  • No input. Autonomous motion.
E

Procedural pattern

No hand-written vertices. A loop builds a dim dotted grid below and a bright centered ring above. Vertex data as computation, not typing.

procedural

10 × 4 grid points below + one centered ring above, all from for loops.

Live data

How it works

  • generated.push(x, y, r, g, b) in a loop.
  • Drawn as POINTS + LINE_STRIP.

Controls

  • No input. Geometry is code.
