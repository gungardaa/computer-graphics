Practicum 1

Graphics Playground

Practicum 1 is the first step into drawing with code. Everything here runs on an HTML canvas: a 2D grid where every point is a coordinate (x, y), and a shape is just a few coordinates plus a color. Each section below demonstrates one requirement of the practicum, and every one of them is live.

800 × 500 canvas 4 primitives 4+ colors triangle from vertices moving objects state-based keyboard mouse coordinates
MAIN

The Playground

Here, you are the graphics engine. Pick a shape, a color, and a stroke width, then drag on the canvas. Every shape stores the same kind of data, including its type, some coordinates, and a color, and is redrawn from scratch every frame.

2

Drag to draw the active shape. Four shapes are already placed for you.

Live data

How it works

  • Each shape is an object: type, coordinates, color, stroke.
  • Pointer down stores the start point; release records the end.
  • The loop repaints every shape each frame.

Controls

  • Drag to draw the active shape.
  • Pick color and stroke before drawing.
  • Undo drops the last shape; Clear empties the canvas.
MOTION

Moving objects

An object at rest is just data. Add input and it moves. The square follows your mouse, the circle answers the keyboard, and both stay inside the canvas. Besides moving, one click can edit data: clicking the square cycles its fill color.

Move the mouse · hold W A S D or arrow keys · click the square.

Live data

How it works

  • The square's position copies the mouse, clamped to the edges.
  • The circle reads a state-based keyboard map every frame.
  • A click hit-test cycles the square's color.

Controls

  • Move the mouse to drag the square.
  • Hold W A S D or arrow keys for the circle.
  • Click the square to cycle its color.
A

Bouncing object

The smallest animation: position, plus velocity, plus a boundary check. Each frame the dot moves by its velocity; each time it hits a wall, the velocity flips so it bounces back.

Click anywhere to teleport the dot.

Live data

How it works

  • position += velocity, every frame.
  • Wall hit? The velocity flips.

Controls

  • Click to teleport the dot.
B

Follow the mouse

Following the mouse is one idea in one line: the circle's position equals the mouse coordinate, read every frame. The dashed guides show it tracking along the x and y axes.

Move the mouse inside the canvas.

Live data

How it works

  • circle.x = mouse.x and circle.y = mouse.y.
  • Clamped so the circle never leaves the canvas.

Controls

  • Move the mouse.
C

Click to change color

A click is an event, and an event edits data. Each click advances an index into a color list; the next frame draws with the new color. Data first, drawing second.

Click to cycle the square's color.

Live data

How it works

  • A color list and an index into it.
  • Click increments the index, wrapping around.

Controls

  • Click the canvas.
D

Move with the keyboard

Movement keys need state, not just events. The page remembers which keys are still held down, and the position is updated from that state every frame, allowing two keys to work at once.

Hold W A S D or the arrow keys.

Live data

How it works

  • keydown and keyup store which keys are held.
  • The update reads the held keys every frame.

Controls

  • Hold W A S D or arrow keys.
E

Mouse coordinate

Every point on the canvas is a pair of numbers. This demo shows the raw (x, y) of the cursor in real time. These are the same numbers that place every shape you draw.

Move the mouse to watch (x, y) update.

Live data

How it works

  • The pointer position is read every time it moves.
  • Both numbers are rounded and drawn each frame.

Controls

  • Move the mouse.
